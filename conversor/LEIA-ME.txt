===================================================================
        MiniMaxBrain (MMB) — Conversão GGUF -> MMBW
===================================================================

1. Coloque um GGUF MoE suportado nesta pasta ou informe o caminho
   completo quando o assistente solicitar.
2. Execute conversor.bat.
3. O conversor:
   - valida a topologia MoE;
   - copia os bytes GGML sem dequantizar/re-quantizar;
   - gera model.mmb-map.json;
   - gera model.mmb-layout.json;
   - gera model.mmb-meta.gguf;
   - grava os pesos em model-*.mmbw;
   - cria gate.json;
   - cria/verifica o selo quando configurado.

Depois da conversão, o runtime normal usa diretamente o bundle MMB:

  Python
    -> mmb_backend.dll
    -> MMBLlamaRuntime
    -> router real
    -> MMBPager
    -> experts .mmbw
    -> GGML MUL_MAT_ID

O GGUF original não é necessário para o chat diário. Ele continua útil
como origem para novas conversões e como baseline de aceite A/B.

Para um bundle já convertido, NAO reconverta. Use:

  python mmb.py prepare --bundle "CAMINHO\modelo-mmbw" --cache-gib 1

Depois:

  python mmb.py chat --bundle "CAMINHO\modelo-mmbw" --ctx 2048 --tokens 128

Consulte ..\README.md e ..\REAL_TESTS.md.
